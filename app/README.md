# 마이문 · Mea Luna / 앱인토스

현재 앱 표기는 **나의 달 · Mea Luna**입니다. 성향 결과에는 ‘이 달의 이야기와 닮은 MBTI’ 카드가 표시됩니다. `src/mbti.ts`는 기존 150개 성향 문구의 주제를 참고한 편집상 비유이며, 생일로 실제 MBTI를 측정하거나 판정하지 않습니다. 결과가 다른 이유를 숨은 성격이나 성격 변화로 단정하지 않습니다.

실제 달의 위상·조명 비율·방위각·고도·월출·월몰을 계산하는 React 18 / TypeScript / Vite 앱입니다. 작업 원본은 `<저장소>/app`, Flutter 원본은 `저장소 루트의 Flutter 원본`에 보관합니다.

## 실행

Node.js 22 이상에서 다음 명령을 실행합니다.

```powershell
cd <저장소>/app
npm install
npm run dev
npm test
npm run build
npm run build:ait
```

`.env.example`을 `.env.local`로 복사하고 콘솔 등록 후 아래 값을 넣습니다.

- `VITE_APP_NAME`: 콘솔의 고유 영문 appName. 현재 `mea-luna`는 등록 전 개발용 이름입니다.
- `VITE_REWARDED_AD_GROUP_ID`: **리워드 광고** 그룹 ID. 전면 광고 ID를 사용하지 마세요.
- `VITE_COPYRIGHT_OWNER`: 실제 저작권자/사업자 표시명.

설정 변경 후 다시 빌드해야 합니다. 앱 이름/브랜드 아이콘/제작자 등은 콘솔에도 등록합니다. 로고와 아이콘은 `public/assets/images/mealuna_logo.png`, `public/assets/icons/app_icon.png`의 원작 파일을 사용합니다.

## 콘텐츠 보존

원작의 `moon_messages.json` 150개와 `moon_fortune_8x30.json` 240개를 파일 그대로 복사했습니다. 달 이름 30개는 Dart 원문에서 추출했습니다. 성향 본문 150개와 달의 상징 설명은 청소년의 자기 존중과 성장을 돕는 시각으로 개정했습니다. 성향 이름·분류·운세 문구는 유지했습니다. 이전 성향 원문은 content-review/2026-10-26/moon_messages.original.json에 보존하며, 테스트는 백업의 원문 동일성과 활성 문안의 이름·분류 보존을 확인합니다.

원본은 생년월일의 평균 삭망월 근사로 달 유형을 구하고, 운세 user_type을 무작위로 골랐습니다. 이 버전은 실제 계산한 태양-달 황경 차를 30구간으로 나눠 원작 유형에 연결합니다. 따라서 경계 날짜에서 원본과 유형이 달라질 수 있습니다. 운세는 태어난 달의 30구간을 8유형에 연결하고, 오늘 한국시간 정오의 위상으로 원작 문구를 선택합니다. 같은 사람의 같은 날은 재접속해도 같은 내용입니다. 태어난 시간 기반 5단계 성향 선택 규칙은 원작 방식 그대로입니다. 시간을 모르면 한국시간 정오를 사용합니다.

원작 30단계 이름 중 일부는 관측용 위상의 일반 명칭과 다릅니다. **나의 달 이름은 원작 그대로**, 실제 관측 영역과 달력은 실제 위상에 따른 일반 명칭을 사용합니다.

## 실제 달 계산

Astronomy Engine의 `MoonPhase`, `Illumination`, `Equator`, `Horizon`, `SearchRiseSet`을 이용합니다. 외부 서버나 API 키 없이 단말에서 계산합니다. 모든 날짜·달력·월출·월몰은 **한국시간 KST** 기준이며, 기기 시간대와 무관합니다. 관측 위치는 기본 서울, 8개 도시 또는 사용자 요청 시 현재 위치로 변경할 수 있습니다. 월출·월몰은 그날 00:00~24:00 사이의 이벤트만 표시하고 없는 날은 '오늘 없음'을 표시합니다.

달이 지평선 아래라면 다음 월출을 안내합니다. 관측 위치는 해발 0m, 표준 대기 굴절을 가정합니다. 산·건물·기상 때문에 실제 보이는 시각은 달라집니다. 달력 이미지는 각 날짜 한국시간 정오입니다. 현재 관측은 30초 주기 및 화면 재진입 때 갱신합니다. 원작 보름달 이미지를 위상에 맞춰 명암 처리하며 실제 촬영 사진/정확한 칭동 재현은 아닙니다.

나침반은 사용자 요청 시 브라우저의 절대 방향 센서 또는 iOS compass heading을 이용합니다. 센서 권한 거절/미지원 시 실제 진북 기준 방위각을 안내합니다. 자북과 진북의 차이, 기울기 및 자기장 간섭에 대한 안내를 제공합니다. 토스 WebView에서 센서 이벤트 지원 여부는 실기기 검증이 필요합니다.

## 앱인토스 연결

- SDK 3.9.0 및 Toss TDS 사용. 토스에서 주요 행동 버튼은 TDS Button과 TDSMobileAITProvider로 표시합니다.
- 토스 내비게이션 및 시스템 뒤로가기를 연결하고, 열린 창이 없으면 미니앱을 닫습니다.
- 사용자 식별키 발급 및 기기 내 저장, 위치 권한 요청, 토스 공유 연결.
- 오늘의 운세는 생년월일 입력 후 ‘광고 보고 오늘의 운세 보기’를 누르고 리워드 광고를 끝까지 시청하면 열립니다.
- 리워드·배너 광고 그룹 ID를 .env.local에 설정했습니다. 운세 광고를 미리 로딩하며 userEarnedReward 이벤트에서만 열람 권한을 부여합니다.
- 당일 열람 권한은 날짜+생년월일+시간별 기기 내 저장. 지난 날짜 기록은 교체됩니다.
- 개발 서버에서만 원문 운세 미리보기 버튼이 나타납니다. 프로덕션 빌드에는 표시되지 않고 열람 권한도 저장하지 않습니다.

## 출시 전에 남은 등록/확인

1. 콘솔에 비게임 미니앱 등록, 실제 appName과 제작자/브랜드 정보를 확정합니다.
2. 리워드 광고 그룹 발급 후 환경 변수에 입력합니다.
3. 실제 사업자/운영자/문의처가 포함된 개인정보처리방침과 이용약관을 확정합니다. 현재 앱의 안내는 처리 내용을 보여주는 개발 단계 안내이며 정식 약관 확정본이 아닙니다.
4. 새 `.ait`를 업로드한 뒤 토스에서 광고 시청·중단·재진입, 위치 허용·거절, 나침반, 뒤로가기, 작은 화면/큰 글꼴을 검증합니다.
5. 토스 공식 검수를 요청합니다. 로컬 빌드 성공은 토스 심사 통과를 의미하지 않습니다.

회원가입, 자체 백엔드 및 개인정보 업로드는 없습니다. 생년월일·시간·지역·식별키·열람 상태는 localStorage에 저장되며 개인정보 안내에서 모두 삭제할 수 있습니다. 기기 변경 간 동기화는 제공하지 않습니다.

### 원본 데이터에서 확인한 오류
운세 user_type=2의 10~19번째 항목은 0~9단계의 번호와 문구가 중복되어 있습니다. 원본 JSON은 바이트 그대로 보존했습니다. 조회할 때만 누락된 10~19단계를 원본 그룹의 해당 순서 항목으로 연결하여 오류 없이 원작 문구가 표시되도록 했습니다. 새 운세 문구는 작성하지 않았습니다.


### 설치된 미리보기 실행
이 노트북에서는 app 폴더의 start-preview.cmd를 실행한 뒤 http://127.0.0.1:5173 을 여세요. 이미 만들어진 dist를 사용하므로 개발 패키지 설치 없이 Node.js만으로 실행할 수 있습니다. 코드를 수정한 뒤에는 npm run build를 먼저 실행하세요.


### 달의 움직임 그래프
오늘 한국시간 00:00부터 24:00까지 선택 지역의 실제 달 고도를 10분 간격으로 계산해 보여줍니다. 실선은 지평선 위, 점선은 지평선 아래이며 현재 시각과 위치를 표시합니다. 달이 지평선 아래에 있어도 그래프는 계속 표시됩니다. 구현은 src/MoonPath.tsx입니다.


### 배너 광고 연결
관측 영역과 달력 사이에 스크롤형 배너 슬롯 1개를 배치했습니다. 콘솔에서 배너 유형 광고 그룹을 만든 뒤 VITE_BANNER_AD_GROUP_ID를 .env.local에 설정하고 다시 빌드하세요. ID 미설정·SDK 미지원·광고 실패 시 슬롯은 숨깁니다. 운세 열기는 광고 시청과 무관합니다. 실제 광고 송출과 복귀 동작은 토스 앱에서 확인해야 합니다.


### 리워드 광고 연결 검증
리워드 완료·중도 종료·표시 실패·로드 실패 후 재시도·사전 로드 공유 동작을 SDK 모의 테스트 3개로 검증했습니다. 실행: node tests/rewarded-ad.test.cjs. 무료 열람 기록과 분리된 reward-unlock 키를 사용합니다. 같은 날 같은 생년월일/시간은 재시청 없이 복원합니다. 실제 토스 광고 송출은 새 mea-luna.ait 업로드 후 확인해야 합니다.
